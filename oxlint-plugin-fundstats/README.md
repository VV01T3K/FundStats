# oxlint-plugin-fundstats

Custom oxlint rules for FundStats, loaded from the repository's `.oxlintrc.json` (`jsPlugins`).

Ported from [t3code](https://github.com/pingdotgg/t3code)'s `oxlint-plugin-t3code`
(MIT, see [LICENSE](./LICENSE)). Each rule has a test next to it that runs the real
oxlint binary on a fixture; run them with `bun run test`.
